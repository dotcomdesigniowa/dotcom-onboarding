## Core principles

### Plan before you act
For any non-trivial task (3+ steps or a real decision), make a short plan and
show it before diving in. A quick obvious fix doesn't need one.

### Verify before you call it done
Never tell me something is done without proving it works. Run it, check it,
show me.

### Aim for elegant, not hacky
On anything non-trivial, ask "is there a cleaner way?" Don't over-engineer a
simple fix.

### When something's broken, just fix it
If I hand you an error, just fix it — you don't need permission for an obvious
bug.

## Workspace hygiene

- **`Company/` is synced from GitHub.** Read it, don't edit it. Josh updates the
  master files and they flow out to you automatically via the daily sync.
- **`Context/` is your personal space.** Edit your own working-style and
  about-me files freely.
- **`Skills/` fills as you work.** Whenever you ask for the same thing twice,
  your OS offers to save it as a skill.
- **`active/` is your scratch space.** Generated work goes here.
- **Never delete files, archive instead.**
- **Working files** stay in `active/`. Don't split by tool (no `active/claude/`
  vs `active/hermes/`). One file, one place.
